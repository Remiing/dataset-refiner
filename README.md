# AI Dataset Viewer

AI 학습용 데이터셋(이미지 및 태그 텍스트)을 빠르고 간편하게 확인하고 수정할 수 있는 웹 기반 뷰어입니다. 
복잡한 설치 없이 브라우저에서 바로 폴더를 불러와 작업할 수 있습니다.

## 주요 기능

- **폴더 일괄 로드**: 이미지 파일과 매칭되는 `.txt` 태그 파일을 한 번에 불러옵니다.
- **태그 관리**: 
  - 특정 태그가 포함된 이미지 필터링
  - 개별 이미지의 태그 추가/삭제 (`+`, `-` 버튼)
  - **트리거 단어(Trigger Word)**: ⭐ 별표로 표시하며 모든 이미지에 일괄 적용 가능
  - **일괄 액션**: 모든 로드된 이미지에 특정 태그를 한 번에 추가(`A+`)하거나 삭제(`A-`)
- **결과물 저장**: 수정된 태그 데이터를 `.zip` 파일로 다운로드

## 사용 방법

1. 상단 **[폴더 선택]** 버튼을 눌러 이미지와 텍스트 파일이 들어있는 폴더를 선택합니다.
2. 왼쪽 **사이드바**에서 태그 목록을 확인하고 필터링합니다.
3. 이미지 카드의 버튼이나 태그의 옵션 버튼을 이용해 데이터를 수정합니다.
4. 작업이 끝나면 **[수정본 다운로드]**를 눌러 결과를 저장합니다.

## 참고 사항

- 이 도구는 서버로 데이터를 전송하지 않습니다. 모든 작업은 사용자의 브라우저 로컬 환경에서 안전하게 처리됩니다.
- 이미지 파일명과 텍스트 파일명이 동일해야 매칭됩니다. (예: `001.jpg` <-> `001.txt`)
